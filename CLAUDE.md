# Vamps

A Three.js + React + TypeScript browser game for GitHub Pages (Vite).
`npm run dev`, `npm run build`, `npm test`. The old C++ terminal game is in
`reference/cpp/` as a rules reference only; it is not built and will be deleted.

**Start every session by reading [docs/WEB_PORT.md](docs/WEB_PORT.md)**: the
design, decisions, open questions and plan of work for the web port. Update it
whenever a decision is made or changed, and add a line to its decision log.
